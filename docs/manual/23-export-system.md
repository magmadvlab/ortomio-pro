# Export: scaricare dati del terreno corretto

L’esportazione produce un file con un insieme preciso di dati. Prima di scaricare scegli terreno, contenuto e periodo; dopo il download controlla che il file corrisponda alla richiesta.

## Dove andare

Apri **Export**. La pagina è intitolata **Export autorizzato**. Serve una sessione valida e l’accesso ai dati scelti.

## Passo per passo

1. In **Orto autorizzato** seleziona il terreno. La pagina può proporre inizialmente il primo disponibile.
2. Scegli il **Dataset**, cioè il contenuto: **Orto**, **Attività**, **Diario**, **Trattamenti** oppure **Dossier**.
3. Compila **Dal** e **Al** per limitare il periodo. Controlla che la data finale non preceda quella iniziale.
4. Scegli **CSV stabile** per lavorare con una tabella, oppure **PDF paginato** per leggere e condividere un documento.
5. Premi **Esporta CSV** o **Esporta PDF**.
6. Attendi il download. Se compare un errore, leggilo prima di ripetere.
7. Apri il file e verifica terreno, periodo, colonne o sezioni e numero di registrazioni.

## Quale contenuto scegliere

**Orto** contiene una configurazione ridotta. **Attività** riguarda task e operazioni. **Diario** riguarda il registro giornaliero. **Trattamenti** riguarda il relativo registro. **Dossier** raccoglie evidenze di certificazione disponibili.

Un CSV può essere aperto con un foglio di calcolo. Controlla separatori, date e unità prima di modificare o aggregare i dati.

## Quando intervenire

Prima di una riunione, una verifica o una consegna documentale, dopo avere controllato i registri. Per periodi diversi genera richieste distinte e usa nomi riconoscibili quando archivi i file.

## Errori e limiti

L’export è per un singolo terreno. Non rappresenta un backup completo dell’account. L’operazione richiede anche la registrazione del download nello storico di controllo: se questo passaggio fallisce, il file può non essere prodotto.

Dati demo e simulazioni non sono evidenze certificative. Un file vuoto può dipendere da periodo, terreno o dati assenti; non prova che l’app abbia perso lo storico.
