# Le parole dell’app, spiegate semplicemente

Usa questo glossario quando una schermata contiene un termine poco familiare. Le definizioni spiegano l’interfaccia e non sostituiscono la formazione tecnica necessaria per intervenire in campo.

## Spazi e organizzazione

| Termine | Significato pratico |
| --- | --- |
| Appezzamento, orto, giardino, garden | Lo spazio agricolo a cui sono collegati i dati. Può contenere ortaggi, alberi o viti. |
| Organizzazione | Il gruppo o l’azienda che riunisce persone e permessi. |
| Zona terreno | Una parte dell’appezzamento che vuoi descrivere separatamente. |
| Zona irrigua | Un settore gestito per l’irrigazione; non coincide automaticamente con una zona terreno. |
| Filare | Una fila o porzione organizzata di coltura. |
| Pianta individuale | Una singola pianta con identificativo, posizione e storia. |
| Lotto o batch | Un gruppo seguito insieme, per esempio piantine della stessa semina. |

## Lavoro e risultati

| Termine | Significato pratico |
| --- | --- |
| Task | Un’attività pianificata, con data e stato. |
| Registro o log | La registrazione di ciò che è avvenuto. |
| Timeline | La cronologia degli eventi. |
| Esito o outcome | Il risultato osservato dopo un intervento. |
| Evidenza | Un’informazione che sostiene una registrazione: misura, data, nota, foto o documento. |
| Ledger | Uno storico strutturato di decisioni e operazioni. |
| Dossier | Una raccolta di documenti ed evidenze; non è una certificazione. |
| Dataset | Il tipo di dati scelto per un’esportazione, per esempio attività o diario. |

## Misure, modelli e servizi

| Termine | Significato pratico |
| --- | --- |
| Dato misurato | Un valore rilevato con una fonte identificabile. Controlla data e unità. |
| Stima o previsione | Un valore calcolato a partire da ipotesi e dati. Può differire dal risultato reale. |
| Confidenza | Indicazione della solidità attribuita alla stima; non garantisce che sia corretta. |
| Fenologia | Lo stadio di sviluppo della pianta osservato o stimato. |
| GDD | Un indicatore del calore accumulato usato dai modelli di sviluppo. |
| NDVI | Un indice ottenuto dalle immagini satellitari, utile per confrontare la vegetazione. |
| VPD | Un indicatore legato alla domanda evaporativa dell’aria. |
| Brix | Un valore rilevato su un campione per descrivere i solidi solubili. |
| ROI | Il rapporto economico tra investimento e ritorno, significativo solo con costi e ricavi attendibili. |
| Provider | Il servizio esterno che fornisce dati o una funzione. |
| API Keys | Credenziali per collegare un servizio. Vanno gestite come segreti. |
| Telemetria | Le misure inviate da un dispositivo. |
| Ack | La conferma ricevuta per un comando; va letta insieme allo stato osservato. |

## Stati da non confondere

**Nessun dato** significa che manca una misura o registrazione, non che il valore sia zero. **Beta** significa che restano verifiche operative. **Simulazione** indica un esempio separato dai dati reali. **Non disponibile** richiede di controllare servizio, autorizzazione o configurazione.

**Previsto**, **inviato**, **confermato** ed **eseguito** sono fasi diverse. Un’attività pianificata non prova il lavoro svolto; un comando inviato non prova che una valvola abbia mosso acqua.
